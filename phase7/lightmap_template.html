Which lights switch on for which job

The model is a tower of 24 floors. Every floor has 3,584 small units, drawn here as dots. A dot lights up when that unit behaves clearly differently during the job you pick. Choose a job, then compare it with another to see whether they share lights.

Strength is how big the difference is, not how sure we are of it (so it is not a confidence interval). Slide right for fewer, stronger lights; slide left to let weaker ones in.

Tidy only moves dots around; no number changes. A unit's seat on its floor is arbitrary, so tidy seats units with the same favourite job (the job they react to most) next to each other: loop first, then each subject, then hard question, then units with no favourite. The same seat on two floors is still not the same unit.

What a light means

Brightness is an effect size (Cohen's d): how far the unit's activity during the job sits from its activity otherwise, in units of its usual spread. 0.8 is the conventional line for a large difference. It measures size, not certainty, so it is not a confidence interval. Hover a dot for its number and whether the unit gets busier or quieter.

Where the numbers come from

"Stuck in a loop" compares the model while it repeats itself with the same answers before the repeating began (80 saved answers). The seven subjects and "Hard question" compare the model while it reads 500 maths questions.

Tidy mode

The order of units inside a floor has no meaning, so tidy mode sorts each floor by the job a unit responds to most. Loop units come first, then each subject, then difficulty, then units with no strong favourite. Favourites are fixed at strength 0.8, so the seating does not move when you drag the slider. Seats do not line up between floors: unit 17 on one floor has nothing to do with unit 17 on the next. Untick it to see the raw order.

What this cannot tell you

Lights show what goes together, not what causes what. Nothing here shows which lights on one floor feed which lights on the next; across floors you can only compare how many are on. In a first test, erasing the "stuck" pattern did not unstick the model, while a random push triggered by the loop lights did. Every question here is maths, so "job" is a narrow idea.
