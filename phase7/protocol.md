# Pre-registered protocol — Phase 7: the matrix atlas ("what maps to what")

No model edits in this phase. The deliverable is a reproducible MAP: which parts of which
weight matrices correspond to which behaviors, centered on (but not limited to) the loop
circuit we have isolated. Every claim carries measured evidence; every plot is generated by
a committed script.

## Deliverables

1. **Loop-circuit atlas** (`phase7/ATLAS.md` + PNG heatmaps):
   - Per-layer × per-column alignment map: every down_proj (and up/gate) column in every
     layer scored by its projection onto the loop direction v — where does the loop circuit
     live, layer by layer?
   - Activation confirmation: forward passes over saved STUCK vs CLEAN generations; which
     intermediate neurons actually fire differently (the "neurons light up" picture); overlay
     with the weight-side map (do the aligned columns coincide with the differentially-active
     ones?).
   - Token map: which vocabulary tokens' embedding rows project onto v; which tokens the
     model emits when v-activation is high (the "Wait, …" family?); which output logits move
     when v is perturbed.
2. **Matrix structure survey**: dominant singular subspaces of the big matrices
   (embed_tokens, per-layer projections), with the loop direction's position within them —
   "what combinations of the matrix" carry the load.
3. **Causal spot-checks**: for the 5 strongest claims in the atlas, tiny single-neuron /
   single-column perturbation experiments (weight edits!) with practice-pass verification —
   the map must predict, not just describe. (These draw from Phase 6's budget if any remains;
   otherwise a small dedicated allowance of 6 passes.)

## Method rules

- Weight-space geometry: unlimited CPU analysis.
- Activation probing: forward passes only (no generation) over generation texts already
  saved in phases 3c/5 — stuck set and clean set are fixed lists committed before probing.
- Plots: matplotlib, committed PNGs, scripts committed; no hand-drawn claims.
- Language: every mapped structure gets coordinates (layer, column ids), an effect size,
  and a confidence label (measured / inferred / speculative).
